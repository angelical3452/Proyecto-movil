Integrantes

Descripción

Maquetación del frontend móvil de una aplicación de control de asistencias, desarrollada con Flutter y Firebase.

Funcionalidades actuales
Inicio de sesión: acceso con correo o nombre de usuario y contraseña, y también con cuenta institucional de Microsoft.
Crear una asignatura: el docente puede crear una asignatura cargando un archivo Excel con la lista de estudiantes.

El resto de las pantallas se encuentra en desarrollo.

Tecnologías
Flutter
Firebase Authentication
Cloud Firestore
